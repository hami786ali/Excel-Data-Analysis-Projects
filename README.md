📊 Excel Data Analysis Projects

📌 About This Repository

This repository showcases my Excel projects completed during the Leep Talents Data Skills Bootcamp.

The projects focus on developing practical skills in data analysis, data organisation, spreadsheet calculations and data visualisation using Microsoft Excel.

Through working with different datasets, I have been developing my ability to organise, explore and interpret data to support data-driven decision-making.

🛠️ Skills and Techniques

The Excel techniques covered during the bootcamp include:

Excel Formulas: SUM, SUMIF, AVERAGE, AVERAGEIF, VLOOKUP, UNIQUE and SWITCH.

Date Functions: DATE, MONTH and YEAR.

Data Organisation: Sorting, filtering and structuring datasets.

PivotTables: Summarising and exploring data.

Data Visualisation: Creating charts and graphs to communicate findings.

Data Analysis: Identifying trends, patterns and relationships within datasets.

📂 Projects and Datasets

1. Retail Sales Analysis

Working with retail sales data to practise spreadsheet calculations, data organisation and analysis.

2. Bike Sales Analysis

Exploring bike sales data through PivotTables and visualisations to practise summarising information and presenting data clearly.

3. Biggest Atlantic Hurricanes

Working with historical hurricane data to develop data exploration and analytical skills.

4. Human Resources Dataset

Using HR-related data to practise organising and analysing structured information.

🎯 Learning Objectives

Through these projects, my goals are to:

Strengthen my Excel and data analysis skills.

Improve my ability to work with different datasets.

Develop confidence in using formulas, functions and PivotTables.

Create clear and informative data visualisations.

Build a portfolio demonstrating my practical analytical skills.
